04Deep Dives

Case Studies

Two websites, walked through step by step — from the idea to the published page. Switch tabs to see each stage.

CASE 01

NeonStream — Movie Streaming Website

Category Frontend Development Role Design & Development Stack HTML5 · CSS3 · JavaScript · Bootstrap 5
The Goal

Build a fully functional movie streaming website where users can browse movie listings, search for a title and open a detail page — with smooth navigation on every device.

Plan the Layout

I broke the design into sections and reusable parts — navbar, movie cards, detail view and footer — so the same components could be used across every page.

Structure & Style

The pages are written in clean, semantic HTML, then styled with CSS and Bootstrap 5 using Flexbox, Grid and media queries so the listings adapt from phone to desktop.

  • Semantic HTML
  • Flexbox & Grid
  • Bootstrap 5
  • Media Queries
Interactivity

JavaScript powers the search and the movement between listings and detail pages, along with menus and small animations that make the site feel alive.

Test & Publish

I checked the site on mobile and desktop browsers, fixed layout issues, and published it with Git & GitHub.

CASE 02

EternalWeb — Gaming Website, Figma to Code

Category UI/UX + Frontend Role Designer & Developer Stack Figma · HTML5 · CSS3 · JavaScript
The Goal

Design and build a gaming website end-to-end — taking it from the first wireframe in Figma all the way to a working, responsive frontend.

User Flow & Wireframe

I mapped the steps a visitor takes through the site, then sketched low-fidelity wireframes for each screen before any color or styling was added.

Visual System

The wireframes were turned into high-fidelity UI with a consistent color, type and icon system, so every section of the site feels like part of the same game world.

  • Color System
  • Typography
  • Icon Set
  • Figma Prototype
Build

I coded the design myself in HTML, CSS and JavaScript, matching the Figma screens closely and using media queries so the layout holds up on every screen size.

Result

A complete gaming website designed and developed by one person — a clear example of my design-to-code workflow.
